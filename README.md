# WearQuote (Moda-App-Shop)

Marketplace de moda donde los clientes pueden comprar diseños de diseñadores
profesionales o describir una prenda personalizada (tela, estilo, hilo, etc.)
y recibir cotizaciones de varios diseñadores.

## Sitio web

Landing page bilingüe (Español 🇵🇷 / English 🇺🇸) en `index.html`.

Para verla localmente:

```
python3 -m http.server 8000
```

y abre `http://localhost:8000`.

## Imágenes

Coloca el logo, favicon e imagen principal en `assets/images/` — ver
`assets/images/README.md` para los nombres de archivo esperados.
