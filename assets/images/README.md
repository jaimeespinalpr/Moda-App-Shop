# Carpeta de imágenes

Deposita aquí las imágenes que quieras usar en la página web. La página ya está
preparada para usar estos nombres de archivo automáticamente (si no existen,
simplemente no se muestran, sin romper el diseño):

| Archivo | Uso | Tamaño sugerido |
|---|---|---|
| `logo.png` | Logo en el header y footer | 120x40px aprox., fondo transparente |
| `favicon.png` | Ícono de la pestaña del navegador | 64x64px |
| `hero.jpg` | Imagen principal en la portada | 1200x900px aprox. |

Si quieres usar otro nombre de archivo o agregar imágenes para la sección de
diseñadores, dime y actualizo el HTML/CSS para que las use.
